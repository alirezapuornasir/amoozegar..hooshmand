# آموزگار هوشمند

سامانه فارسی و راست‌چین آمادگی آزمون استخدامی آموزگار ابتدایی، تحلیل عملکرد و آموزش هوش ریاضی. این پروژه **چندفایلی، بدون مرحله build و مناسب GitHub Pages** است؛ هیچ پکیج، نصب‌کننده، Cloudflare، Netlify یا سرور جداگانه‌ای برای اجرای نسخه فعلی لازم نیست.

## امکانات پیاده‌سازی‌شده

- بانک تمرینی ۲۲۰۰ سؤالی با چهار گزینه و پاسخ تشریحی:
  - ۱۰۰۰ سؤال حیطه تخصصی و آموزشی
  - ۱۰۰۰ سؤال دروس ابتدایی
  - ۲۰۰ سؤال هوش ریاضی
- آزمون‌های ۱۰، ۲۰، ۳۰ و ۵۰ سؤالی؛ فیلتر درس، موضوع/سطح؛ ترتیب تصادفی؛ زمان‌سنج؛ نشان‌گذاری و جابه‌جایی بین سؤال‌ها؛ تصحیح خودکار.
- کارنامه با درصد کلی و تفکیک درس، پاسخ‌نامه تشریحی، تاریخچه، شناسایی درس‌های ضعیف و ذخیره اشتباهات.
- جست‌وجوی بانک سؤال و نشان‌کردن سؤال‌های منتخب.
- دستیار آموزشی آفلاین متکی به درس‌نامه‌ها و بانک داخلی، پیشنهاد آزمون و توضیح پاسخ‌های مرتبط.
- درس‌نامه‌های آموزشی، فلش‌کارت‌های خودکار و شخصی، برنامه مطالعه، هدف روزانه، زمان‌سنج تمرکز و دفترچه یادداشت.
- ۲۰۰ تست هوش ریاضی، درس‌نامه روش حل و فهرست جست‌وجوی ویدیوهای آموزشی YouTube.
- ذخیره محلی، خروجی/ورودی پشتیبان، حالت تاریک و Service Worker برای cache فایل‌های برنامه.
- رابط راست‌چین و واکنش‌گرا؛ manifest و آیکن‌های نصب اندروید.

## انتشار در GitHub فقط

1. همه محتویات این پوشه را در ریشه مخزن GitHub بارگذاری کن؛ یعنی `index.html` باید مستقیماً در ریشه مخزن باشد، نه داخل یک پوشه اضافی.
2. همه پوشه‌ها از جمله `assets`، `data`، `.github` و `scripts` را هم بارگذاری کن. فایل‌ها را جابه‌جا یا نام‌گذاری مجدد نکن.
3. Commit را روی شاخه `main` انجام بده.
4. در مخزن، وارد `Settings → Pages` شو و در بخش `Build and deployment` گزینه `GitHub Actions` را برای Source انتخاب کن.
5. به زبانه `Actions` برو. گردش کار `Deploy آموزگار هوشمند to GitHub Pages` با هر Push اجرا می‌شود. پس از موفقیت، URL در جزئیات اجرای workflow یا `Settings → Pages` نمایش داده می‌شود.
6. لینک HTTPS سایت را در Chrome اندروید باز کن و از منوی سه‌نقطه گزینه `Install app` یا `Add to Home screen` را انتخاب کن.

هیچ `npm install`، build، CLI یا برنامه دیگری لازم نیست.

## ویرایش و افزایش بانک سؤال

فایل‌های JSON سه دسته سؤال را نگه می‌دارند. هر سؤال این ساختار را دارد:

```json
{
  "id": "شناسه یکتا",
  "domain": "professional",
  "subject": "نام درس",
  "topic": "موضوع",
  "difficulty": "متوسط",
  "question": "متن سؤال",
  "options": ["گزینه ۱", "گزینه ۲", "گزینه ۳", "گزینه ۴"],
  "answer": 0,
  "explanation": "توضیح تشریحی"
}
```

`answer` شماره گزینه صحیح از صفر تا سه است. بعد از ویرایش JSON، فایل‌ها را Commit کن؛ GitHub Pages تغییرات را منتشر می‌کند. فایل `scripts/build_bank.py` سازنده بانک پارامتری اولیه است؛ اجرای آن فقط برای توسعه‌دهنده‌ای است که بخواهد داده‌ها را بازتولید کند و برای کاربر نهایی لازم نیست.

## محدودیت‌های واقعی نسخه GitHub-only

- **هوش مصنوعی مولد واقعی در این نسخه وجود ندارد.** GitHub Pages فقط فایل‌های استاتیک را میزبانی می‌کند. دستیار فعلی آفلاین و مبتنی بر جست‌وجوی محتوا/درس‌نامه است. برای اتصال امن به مدل زبانی واقعی، backend و نگهداری secret خارج از فایل عمومی لازم می‌شود؛ API key را هرگز در JavaScript عمومی قرار نده.
- **داده‌های آزمون و یادداشت‌ها فقط در همان مرورگر و دستگاه ذخیره می‌شوند** و خودکار بین گوشی و رایانه همگام نمی‌شوند. برای انتقال از پشتیبان JSON استفاده کن.
- ویدیوها با جست‌وجوی YouTube باز می‌شوند و اینترنت/سرویس YouTube لازم دارند؛ فایل ویدیو داخل مخزن نیست.
- بانک سؤال فعلی ۲۲۰۰ سؤال تمرینی تألیفی و پارامتری دارد. این بانک رسمی نیست و نباید به‌عنوان سؤالات واقعی یا تضمین‌شده آزمون استخدامی معرفی شود. پیش از اتکا، محتوا را با منابع و سرفصل‌های رسمی آزمون خودت تطبیق بده. برخی قالب‌ها برای پوشش شمار هدف، نمونه‌های متغیر از یک مهارت را می‌سازند؛ «۲۲۰۰» به معنی ۲۲۰۰ سؤال رسمی یا بازبینی‌شده توسط مرجع آزمون نیست.
- Service Worker فقط بعد از اولین بارگذاری موفق و از طریق HTTPS فعال می‌شود. برخی امکانات مانند YouTube با قطع اینترنت در دسترس نیستند.

## حریم خصوصی

هیچ داده‌ای به سرور پروژه ارسال نمی‌شود. اطلاعات شخصی روی مرورگر کاربر و با `localStorage` نگهداری می‌شود. با پاک‌کردن داده‌های سایت ممکن است کارنامه‌ها حذف شوند؛ پیش از آن پشتیبان بگیر.
